## Invariant Tests Added

### 1. testFreezeEconomicsInvariants()
**Purpose**: Verify freeze captures immutable snapshots of shares and assets

**Invariants Tested**:
- INVARIANT 1: frozenShares equals totalSharesPending at freeze time
- INVARIANT 2: frozenAssets equals totalAssets() at freeze time
- INVARIANT 3: After freeze, frozenShares and frozenAssets are immutable
- INVARIANT 4: proRataRatio is initially set to PRORATA_PRECISION (1e18)
- INVARIANT 5: Epoch status transitions from Active -> Frozen
- INVARIANT 6: All pending requests transition to Frozen status

### 2. testCarryConservationInvariant()
**Purpose**: Verify carry conservation equation holds across cohort

**Invariants Tested**:
- INVARIANT 1: cohortTotalClaimed + cohortCarryRemaining == cohortTotalEntitlement
- INVARIANT 2: Sum of individual request accrued + claimed matches cohort totals
- INVARIANT 3: Each request's entitlement = assetsClaimable + accrued (carry)
- INVARIANT 4: After partial claim, conservation equation still holds
- INVARIANT 5: After full claim, carryRemaining should be 0 for that request
- INVARIANT 6: Request status transitions correctly to Claimed

### 3. testThresholdDustInvariant()
**Purpose**: Verify dust handling and claim threshold behavior

**Invariants Tested**:
- INVARIANT 1: Regular redeem/withdraw below threshold reverts before finalization
- INVARIANT 2: Dust claim reverts before finalization
- INVARIANT 3: After finalization, dust claim succeeds if amount < MIN_CLAIM_THRESHOLD
- INVARIANT 4: After dust claim, request status is Claimed
- INVARIANT 5: After finalization, regular redeem allows amounts below threshold

### 4. testChunkedSettlementInvariant()
**Purpose**: Verify chunked settlement processes all requests correctly

**Invariants Tested**:
- INVARIANT 1: Settlement processes all requests across chunks (150 requests in 2 chunks)
- INVARIANT 2: Cannot start chunk from wrong index
- INVARIANT 3: Resume from correct index and complete
- INVARIANT 4: All requests have Claimable status after settlement
- INVARIANT 5: Epoch status is Settled after complete settlement
- INVARIANT 6: Cannot process more chunks after completion
- INVARIANT 7: Each request has correct entitlement and assetsClaimable
