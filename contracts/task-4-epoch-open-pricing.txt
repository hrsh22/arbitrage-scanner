### 4. processDepositQueue uses epochOpenNAV with boundary check (lines 261-277):
```solidity
function processDepositQueue(uint256 epochId, uint256 startIndex, uint256 endIndex) 
    external onlyRole(DEPOSIT_PROCESSOR_ROLE) nonReentrant 
{
    Epoch storage epoch = epochs[epochId];
    if (!epoch.exists) revert InvalidRequest(epochId);
    if (epoch.status != EpochStatus.Active && epoch.status != EpochStatus.Frozen) 
        revert EpochNotActive(epochId);
    if (block.timestamp < epoch.startTime)  // BOUNDARY CHECK
        revert EpochNotActive(epochId);
    
    uint256[] storage requests = epochDepositRequests[epochId];
    if (endIndex > requests.length) endIndex = requests.length;
    
    for (uint256 i = startIndex; i < endIndex; i++) {
        DepositRequest storage request = depositRequests[requests[i]];
        if (!request.exists || request.processed) continue;
        
        // Use epochOpenNAV instead of currentNAV
        uint256 shares = _convertAssetsToShares(request.assets, epoch.epochOpenNAV);
        _mint(request.depositor, shares);
        request.processed = true;
        totalQueuedAssets -= request.assets;
        emit DepositProcessed(request.requestId, request.depositor, request.assets, shares, epochId);
    }
}
```

## Key Semantics

1. **epochOpenNAV**: Captured once when epoch opens (status changes to Active)
2. **Delayed Mint**: Uses epochOpenNAV for all deposit processing in that epoch
3. **Boundary Guard**: Mint blocked before epoch.startTime
4. **No Runtime NAV**: Conversion uses snapshot, not currentNAV
