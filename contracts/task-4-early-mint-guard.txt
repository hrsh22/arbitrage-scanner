TASK 4 EVIDENCE: Early Mint Guard
==================================

## Implementation

### Boundary Check in processDepositQueue (line 265):
```solidity
if (block.timestamp < epoch.startTime) revert EpochNotActive(epochId);
```

This check ensures:
1. Minting cannot occur before the epoch's official start time
2. Deposit queue processing is blocked until `block.timestamp >= epoch.startTime`
3. Uses existing `EpochNotActive` error for consistency

## Context

The boundary check works in conjunction with the epoch-open NAV pricing:
- Epoch 0: `epochOpenNAV = 1e18` (set in constructor)
- Future epochs: `epochOpenNAV = currentNAV` (captured in freezeEpoch)
- Processing: Uses `epoch.epochOpenNAV` (not runtime `currentNAV`)
- Timing: Blocked until `block.timestamp >= epoch.startTime`
