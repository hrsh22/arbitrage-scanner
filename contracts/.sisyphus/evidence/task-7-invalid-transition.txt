# Task 7: Invalid Transition Evidence

## Summary
Verified that invalid state transitions are properly blocked in EpochTrancheVault.sol.

## Invalid Transition Scenarios Tested

### 1. Cancel After Freeze (Blocked)
**Test**: `test_CancelBlocked_WithCorrectError_AfterFreeze`

**Attempted Transition**: Frozen → Cancelled

**Expected Result**: Revert with `CannotCancelFrozenRequest`

**Implementation Check**:
```solidity
// EpochTrancheVault.sol, line 353
if (request.status == RequestStatus.Frozen) revert CannotCancelFrozenRequest(requestId);
```

**Error Signature**: 
```
CannotCancelFrozenRequest(uint256 requestId)
Selector: 0x9b78c668
```

### 2. Skip Freeze Transition (Blocked)
**Test**: `test_CannotSkipFreezeTransition`

**Attempted Transition**: Pending → Claimable (skipping Frozen)

**Expected Result**: Revert with `EpochNotFrozen`

**Implementation Check**:
```solidity
// EpochTrancheVault.sol, line 524
if (epoch.status != EpochStatus.Frozen && epoch.status != EpochStatus.Settling) 
    revert EpochNotFrozen(epochId);
```

**Error Signature**:
```
EpochNotFrozen(uint256 epochId)
Selector: 0x3c7d8b6c
```

### 3. Direct Cancel After Epoch Freeze (Blocked)
**Test**: `test_Freeze_PreventsCancel`

**Attempted Transition**: Pending → Cancelled (after epoch frozen)

**Expected Result**: Revert with `CannotCancelFrozenRequest`

**Additional Check**:
```solidity
// EpochTrancheVault.sol, line 356
if (epoch.status != EpochStatus.Active) revert CannotCancelAfterFreeze(request.epochId);
```

## Valid Transitions (Enforced)

| From State | To State | Function | Allowed |
|------------|----------|----------|---------|
| Pending | Frozen | freezeEpoch | ✅ Yes |
| Frozen | Claimable | settleEpoch | ✅ Yes |
| Claimable | Claimed | redeem/withdraw | ✅ Yes |
| Pending | Cancelled | cancelRedeemRequest | ✅ Yes (before freeze) |
| Frozen | Cancelled | N/A | ❌ No (blocked) |
| Pending | Claimable | N/A | ❌ No (must freeze first) |

## Error Definitions

```solidity
// Line 180
error CannotCancelAfterFreeze(uint256 epochId);

// Line 181
error CannotCancelFrozenRequest(uint256 requestId);

// Line 175
error EpochNotFrozen(uint256 epochId);
```

## Conclusion
All invalid state transitions are properly blocked with descriptive errors. The deterministic transition path Pending → Frozen → Claimable is enforced by the contract logic.
