# Task 14: Repository API Evidence - Cohort-Carry Lifecycle

## Summary
Migrated DB schema, repositories, and claim state machine to cohort-carry lifecycle.

## Repository APIs - Cohort-Carry Lifecycle

### Epoch Repository
- Status Enum: `pending -> frozen -> claimable -> closed`
- New Methods:
  - `freezeEpoch(epochId)` - Transition to frozen state
  - `makeEpochClaimable(epochId)` - Transition to claimable state
  - `closeEpoch(epochId)` - Transition to closed state
  - `getFrozenEpoch(vaultAddress)` - Get frozen epoch for vault
- Updated Transitions:
  - `pending: ["frozen", "cancelled"]`
  - `frozen: ["claimable", "cancelled"]`
  - `claimable: ["closed", "cancelled"]`
  - `closed: []` (terminal)

### Epoch Request Repository
- Status Enum: `pending -> frozen -> claimable -> claimed -> closed`
- New Methods:
  - `freezeRequest(requestId)` - Transition to frozen
  - `makeRequestClaimable(requestId, claimableAssets)` - Make claimable
  - `closeRequest(requestId)` - Close request
  - `getFrozenRequestsForEpoch(epochId)` - Get frozen requests
- Updated Transitions:
  - `pending: ["frozen", "cancelled"]`
  - `frozen: ["claimable", "cancelled"]`
  - `claimable: ["claimed", "closed"]`
  - `claimed: ["closed"]`
  - `closed: []` (terminal)

### Entitlement Repository
- New Fields: `trancheId`, `entitlement`, `accrued`, `claimed`, `carryRemaining`
- Status Enum: `pending -> frozen -> claimable -> partially_fulfilled -> fully_fulfilled -> closed`
- New Methods:
  - `freezeEntitlement(entitlementId, calculatedEntitlement)` - Freeze with entitlement
  - `accrueAmount(entitlementId, amount)` - Accrue from realizations
  - `updateCohortCarry(entitlementId, updates)` - Update carry fields
  - `getByTranche(trancheId)` - Get by cohort tranche
  - `getTotalAccruedForEpoch(epochId)` - Total accrued
  - `getTotalCarryRemainingForEpoch(epochId)` - Total carry remaining

### Realization Repository
- New Field: `trancheId`
- Updated Methods:
  - `create(input)` - Accepts optional trancheId
  - `processRealization(input)` - Distributes to entitlements with cohort tracking
  - `getByTranche(trancheId)` - Get by tranche

### Payout Repository
- New Fields: `trancheId`, `entitlementAmount`, `carryForward`
- Updated Methods:
  - `create(input)` - Accepts trancheId and cohort fields
  - `markClaimed(payoutId, txHash)` - Updates entitlement claimed/carryRemaining
  - `getByTranche(trancheId)` - Get by tranche
  - `getTotalByTranche(trancheId)` - Total by tranche
  - `getCohortCarryStats(epochId)` - Cohort-carry statistics

## State Transition Matrices

### Epoch States
```
pending -> frozen -> claimable -> closed
    |          |           |
    v          v           v
cancelled  cancelled   cancelled
```

### Epoch Request States
```
pending -> frozen -> claimable -> claimed -> closed
    |          |           |         |
    v          v           v         v
cancelled  cancelled   cancelled  cancelled
```

### Entitlement States
```
pending -> frozen -> claimable -> partially_fulfilled -> fully_fulfilled -> closed
              |           |                                              |
              v           v                                              v
         cancelled    cancelled                                      cancelled
```
