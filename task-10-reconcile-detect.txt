1. FIELD MAPPING DOCUMENTATION
================================================================================

Explicit mapping between canonical and legacy fields:

Canonical Schema (single source of truth):
  - entitlement:        Total entitled amount (immutable after freeze)
  - accrued:            Amount accrued from realizations
  - claimed:            Amount claimed by user
  - carryRemaining:     Remaining to be carried (calculated: entitlement - claimed)

Legacy Schema (deprecated, maintained for backward compatibility):
  - totalRealizedUsdc:  Maps to 'accrued'
  - totalClaimedUsdc:   Maps to 'claimed'

================================================================================
2. MISMATCH DETECTION CAPABILITIES
================================================================================

The following mismatch types are detected and logged with deterministic reasons:

A. CANONICAL_LEGACY_ACCRUED_MISMATCH
   Trigger: accrued (canonical) != totalRealizedUsdc (legacy)
   Logged with: entitlementId, requestId, userAddress, both values
   
B. CANONICAL_LEGACY_CLAIMED_MISMATCH
   Trigger: claimed (canonical) != totalClaimedUsdc (legacy)
   Logged with: entitlementId, requestId, userAddress, both values
   
C. CARRY_REMAINING_CALCULATION_ERROR
   Trigger: carryRemaining != entitlement - claimed
   Logged with: current, expected, entitlement, claimed values
   
D. CONTRACT_REPOSITORY_MISMATCH
   Trigger: Repository state differs from on-chain contract state
   Logged with: repository value, contract value, field name
