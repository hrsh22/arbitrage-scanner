1. ZERO UNEXPLAINED DELTAS REQUIREMENT
================================================================================

The reconciliation system reports zero unexplained deltas when:

1. All canonical fields match their legacy counterparts:
   - accrued == totalRealizedUsdc
   - claimed == totalClaimedUsdc

2. carryRemaining is correctly calculated:
   - carryRemaining == entitlement - claimed

3. No contract/repository mismatches exist (when contract state provided)

4. ISRECONCILED() API
================================================================================

Method: entitlementRepository.isReconciled(epochId, contractStates?)

Returns:
{
  reconciled: boolean,  // true if unexplainedDeltas === 0
  report: ReconciliationReport
}

Usage for health checks:
```typescript
const { reconciled, report } = await repo.isReconciled("epoch-1");
if (!reconciled) {
  alert(`Reconciliation failed: ${report.summary.unexplainedDeltas} unexplained deltas`);
}
```
