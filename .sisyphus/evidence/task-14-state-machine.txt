## State Mapping from DB Status

```typescript
function mapRequestStatusToClaimState(requestStatus: string, entitlementStatus?: string): ClaimState {
  // Check entitlement status first for realized states
  if (entitlementStatus) {
    switch (entitlementStatus) {
      case "partially_fulfilled":
      case "fully_fulfilled":
        return ClaimState.CLAIMED;
      case "pending":
      case "frozen":
        return ClaimState.FROZEN;
      case "claimable":
        return ClaimState.CLAIMABLE;
      case "closed":
        return ClaimState.CLOSED;
    }
  }

  // Fall back to request status
  switch (requestStatus) {
    case "pending": return ClaimState.PENDING;
    case "frozen": return ClaimState.FROZEN;
    case "claimable": return ClaimState.CLAIMABLE;
    case "claimed": return ClaimState.CLAIMED;
    case "closed": return ClaimState.CLOSED;
    case "cancelled": return ClaimState.CLOSED;
    default: return ClaimState.PENDING;
  }
}
```

## State Machine Helpers

### Transition Checks
- `isValidClaimTransition(fromState, toState)` - Check if transition is valid
- `validateClaimTransition(fromState, toState)` - Validate with error message
- `canFreeze(currentState)` - Check if can freeze
- `canMakeClaimable(currentState)` - Check if can make claimable
- `canClose(currentState)` - Check if can close

### Operation Checks
- `isValidOperationForState(operation, state)` - Check if operation valid for state
- `validateClaimOperation(operation, state)` - Validate with error message
- `getAvailableOperations(currentState)` - Get allowed operations
- `getAvailableTransitions(currentState)` - Get allowed transitions

### Guard Function

```typescript
function guardClaimOperation(options: {

```

## Lifecycle Flow

```
User creates request
        |
        v
    PENDING (can view, cancel, or freeze)
        |
        | Epoch freeze event
        v
    FROZEN (can view history, process realizations)
        |
        | Realization events
        v
  CLAIMABLE (can claim, view history, close)
        |
        | User claims payouts
        v
   CLAIMED (can view history, close)
        |
        | All payouts settled
        v
    CLOSED (terminal - view only)
```

## Enforcement Points

1. **Repository Level**: Epoch and entitlement repositories validate transitions
2. **State Machine Level**: `isValidClaimTransition` guards state changes
3. **Operation Level**: `guardClaimOperation` validates operation permissions
4. **API Level**: Routes use guard functions before processing
