Task 2: Epoch Boundaries Evidence
=====================================

Summary:
Extended EpochMath library with deterministic boundary check functions for deposit cutoff,
mint-open boundary, redemption freeze boundary, and claim window checks.

New Functions Added to EpochMath.sol:
-------------------------------------

1. isDepositAllowed(genesis, duration, timestamp, depositCutoffOffset)
   - Returns true if current time is before deposit cutoff for the epoch
   - Boundary: [epoch_start, epoch_end - depositCutoffOffset)

2. isMintOpen(genesis, duration, timestamp, mintOpenOffset)
   - Returns true if minting is open for the current epoch
   - Boundary: [epoch_start + mintOpenOffset, epoch_end)

3. isRedemptionFrozen(genesis, duration, timestamp, redemptionFreezeOffset)
   - Returns true if redemptions are frozen for the current epoch
   - Boundary: [epoch_end - redemptionFreezeOffset, epoch_end)

4. isClaimWindowOpen(genesis, duration, settledEpoch, timestamp, claimWindowDuration, settlementTimestamp)
   - Returns true if claim window is still open after settlement
   - Boundary: [settlementTimestamp, settlementTimestamp + claimWindowDuration)

5. getConfigActivationTime(genesis, duration, currentTimestamp, activationDelayEpochs)
   - Returns (effectiveEpoch, effectiveTimestamp) when config change takes effect
   - Formula: currentEpoch + 1 + activationDelayEpochs

6. shouldUseOriginalConfig(genesis, duration, requestQueueEpoch, configEffectiveEpoch)
   - Returns true if queued request should use original config (not updated)
   - Logic: requestQueueEpoch < configEffectiveEpoch

7. getDepositCutoffTime(genesis, duration, epoch, depositCutoffOffset)
   - Returns the exact timestamp when deposits close for a specific epoch

8. getRedemptionFreezeStart(genesis, duration, epoch, redemptionFreezeOffset)
   - Returns the exact timestamp when redemptions freeze for a specific epoch

Key Boundary Behaviors Verified:
--------------------------------
1. At exact epoch boundary: behavior transitions to next epoch's rules
2. Deposit cutoff: strictly before cutoff time (timestamp < cutoff)
3. Mint open: at or after open time (timestamp >= openTime)
4. Redemption freeze: at or after freeze start (timestamp >= freezeStart)
5. Claim window: inclusive at start, exclusive at end [start, end)
