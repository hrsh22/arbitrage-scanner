## 4. KNOWN ISSUE: DUPLICATE IERC20 INTERFACES

### Problem
`EpochTrancheVault` imports both `IERC20` (directly) and `ERC20` (which transitively imports `IERC20` via multiple paths). When flattened, `forge` creates suffixed variants:

| Variant | Source Path | Inheritance |
|---------|-------------|-------------|
| `IERC20_0` | `token/ERC20/IERC20.sol` | Base interface |
| `IERC20_1` | `interfaces/IERC20.sol` | Used by IERC20Metadata |

### Raw Flatten Output Analysis
```
Line  611: // ../lib/openzeppelin-contracts/contracts/token/ERC20/IERC20.sol
Line  618: interface IERC20_0 { ... }

Line  690: // /Users/harsh/Developer/polymarket-mvp/lib/openzeppelin-contracts/contracts/token/ERC20/IERC20.sol
Line  697: interface IERC20_1 { ... }

Line 1112: interface IERC20Metadata is IERC20_1 { ... }

Line 1471: abstract contract ERC20 is Context, IERC20_0, IERC20Metadata, IERC20Errors { ... }
```

### Impact
- **SafeERC20** uses `IERC20_0` (correct)
- **IERC20Metadata** extends `IERC20_1` (must remain consistent)
- **ERC20** implements both `IERC20_0` and `IERC20Metadata`

### Dedupe Rule
**ACCEPT the dual-interface pattern as generated by `forge flatten`.**

Rationale:
1. `forge` automatically handles name collisions via `_N` suffixing
2. `IERC20_0` and `IERC20_1` are functionally identical interfaces
3. OpenZeppelin's `IERC20Metadata` inherits from `IERC20` - keeping `IERC20_1` preserves this inheritance chain
4. Remix compiles successfully with this pattern (precedent: SnapshotTrancheVault-Remix.sol)

**Do NOT manually merge interfaces** - this risks breaking the inheritance graph.

### T12 Validation (CI/CD Integration)
```bash
# CI/CD pipeline validation

#!/bin/bash
set -e

FLATTEN_FILE="flattened/EpochTrancheVault-Remix.sol"

# Validation 1: SPDX License
echo "Checking SPDX license count..."
SPDX_COUNT=$(grep -c "^// SPDX-License-Identifier:" "$FLATTEN_FILE" || true)
if [ "$SPDX_COUNT" -ne 1 ]; then
    echo "FAIL: Expected 1 SPDX identifier, found $SPDX_COUNT"
    exit 1
fi
echo "PASS: SPDX license count = 1"

# Validation 2: No import statements
echo "Checking import statements..."
IMPORT_COUNT=$(grep -c "^import " "$FLATTEN_FILE" || true)
if [ "$IMPORT_COUNT" -ne 0 ]; then
    echo "FAIL: Expected 0 import statements, found $IMPORT_COUNT"
    exit 1
fi
echo "PASS: Import statement count = 0"

# Validation 3: Main contract exists
echo "Checking main contract..."
if ! grep -q "^contract EpochTrancheVault" "$FLATTEN_FILE"; then
    echo "FAIL: Main contract EpochTrancheVault not found"
    exit 1
fi
echo "PASS: Main contract EpochTrancheVault found"

# Validation 4: Expected interface variants
echo "Checking IERC20 variants..."
if ! grep -q "^interface IERC20_0" "$FLATTEN_FILE"; then
    echo "FAIL: IERC20_0 interface not found"
    exit 1
fi
if ! grep -q "^interface IERC20_1" "$FLATTEN_FILE"; then
    echo "FAIL: IERC20_1 interface not found"
    exit 1
fi
echo "PASS: IERC20 variants present"

echo ""
echo "=== All validations passed ==="
```
