```typescript
const queuedAssets = Number(formatUnits(totalQueuedAssetsRaw, USDC_DECIMALS));
const reservedRedemptionAssets = Number(
  formatUnits(reservedRedemptionAssetsRaw, USDC_DECIMALS),
);
const vaultUsdc = Number(formatUnits(vaultUsdcRaw, USDC_DECIMALS));
const safeUsdc = Number(formatUnits(safeUsdcRaw, USDC_DECIMALS));
const grossIdleAssets = vaultUsdc + safeUsdc;
const grossTotalAssets = grossIdleAssets + deployedMarketValue;
const excludedAssets = queuedAssets + reservedRedemptionAssets;  // <-- EXCLUSION
const idleAssets = Math.max(grossIdleAssets - excludedAssets, 0);
const totalAssets = Math.max(grossTotalAssets - excludedAssets, 0);  // <-- BOUNDARY NAV
```

### Lines 798-801: Share Price Calculation
```typescript
const totalSupply = Number(formatUnits(totalSupplyRaw, USDC_DECIMALS));
const pricingSupplyRaw = totalSupplyRaw + totalPendingRedeemSharesRaw;
const pricingSupply = Number(formatUnits(pricingSupplyRaw, USDC_DECIMALS));
const sharePrice = pricingSupply > 0 ? totalAssets / pricingSupply : 1.0;
```

Key points:
- totalAssets EXCLUDES queuedAssets and reservedRedemptionAssets
- pricingSupply INCLUDES totalPendingRedeemShares (correct for pro-rata)
- This is the boundary NAV semantics

```typescript
  const navStatus = await this.client.getNAVStatus();
  if (navStatus.currentNAV === 0n) return shares;
  return (shares * navStatus.currentNAV) / 10n ** 18n;  // Uses boundary NAV
}
```

## Contract-Level Evidence


The contract's `currentNAV()` function is the authoritative source for boundary pricing.
Per the contract design:
- Queued deposits are isolated until epoch opens
- Reserved redemption assets are excluded from deployable capital
- NAV = (totalAssets - queued - reserved) / (totalSupply + pendingRedeemShares)
