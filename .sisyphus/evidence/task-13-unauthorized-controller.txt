# Task 13: Edge Case Tests - Unauthorized Controller Evidence

## Summary
Successfully implemented edge case tests for unauthorized controller access in WeeklyEpochVault.

## Test Results
All unauthorized controller tests pass (6 tests):

1. **testUnauthorizedControllerCannotRedeem** ✅
   - Attacker cannot redeem on behalf of victim
   - Reverts with `NotController(controller, attacker)`

2. **testUnauthorizedControllerCannotWithdraw** ✅
   - Attacker cannot withdraw on behalf of victim
   - Reverts with `NotController(controller, attacker)`

3. **testControllerCannotRedeemForDifferentController** ✅
   - User2 cannot redeem on behalf of User1
   - Reverts with `NotController(user1, user2)`

4. **testRedeemRequiresControllerOrOperator** ✅
   - Random user cannot redeem for any controller
   - Reverts with `NotController(controller, caller)`

5. **testWithdrawRequiresControllerOrOperator** ✅
   - Random user cannot withdraw for any controller
   - Reverts with `NotController(controller, caller)`

6. **testRevokedOperatorCannotRedeemForController** ✅
   - Revoked operator cannot redeem for controller
   - Reverts with `NotController(controller, operator)`

## Key Findings

### Authorization Checks
Both `redeem()` and `withdraw()` enforce:
```solidity
if (msg.sender != controller && !isOperator[controller][msg.sender]) {
    revert NotController(controller, msg.sender);
}
```

### Access Control Matrix
| Caller | Can Redeem For Controller | Can Withdraw For Controller |
|--------|---------------------------|----------------------------|
| Controller (self) | ✅ Yes | ✅ Yes |
| Approved Operator | ✅ Yes | ✅ Yes |
| Revoked Operator | ❌ No (NotController) | ❌ No (NotController) |
| Random User | ❌ No (NotController) | ❌ No (NotController) |
| Different Controller | ❌ No (NotController) | ❌ No (NotController) |

### Security Properties
- Authorization is strictly enforced
- No bypass possible through different error conditions
- Error messages clearly identify expected vs actual caller
- Operator status is checked atomically with each call
