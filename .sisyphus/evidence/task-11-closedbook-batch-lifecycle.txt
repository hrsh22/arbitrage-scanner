================================================================================
CLOSED-BOOK BATCH LIFECYCLE (Correct)
================================================================================

Request Phase:
  - User calls queueDeposit(assets) → deposit queued for next batch
  - User can call requestRedeem(shares, controller, owner) → redemption request created

Operator Phase 1 - Cutoff:
  - SNAPSHOT_ROLE calls cutoffBatch()
  - Transition: Open → Cutoff
  - No new deposits or redemptions accepted

Operator Phase 2 - Flatten:
  - SNAPSHOT_ROLE calls flattenBatch(snapshotHash)
  - Transition: Cutoff → Flattening
  - Locks clearing price (excludes sealed/queued deposits)
  - Takes NAV snapshot
  - Evidence: isPriceLocked = true, lockedClearingPrice > 0

Operator Phase 3 - Process Deposits:
  - DEPOSIT_PROCESSOR_ROLE calls processDepositQueue(batchId, startIndex, endIndex)
  - Mints shares at the LOCKED clearing price
  - All deposits in batch mint at SAME price

Operator Phase 4 - Settle:
  - SETTLER_ROLE calls settleBatch(batchId)
  - Transition: Flattening → Settled
  - Computes claimable assets for redemptions
  - Applies pro-rata ratio if insufficient assets
  - Evidence: settlementProgress.complete = true

Claim Phase:
  - Users call redeem(requestId, shares, receiver) or withdraw(requestId, assets, receiver)
  - Claims available immediately after settlement

Operator Phase 5 - Reopen:
  - ADMIN_ROLE calls reopenBatch()
  - Creates new batch with Open status
  - New batch ready for deposits

================================================================================
BATCH STATUS ENUM
================================================================================

0 = Open       - Accepting deposits and redemptions
1 = Cutoff     - Deposits closed, redemptions frozen
2 = Flattening - NAV snapshot taken, positions marked, price locked
3 = Settling   - Settlement in progress (chunked)
4 = Settled    - Settlement complete, claims available
5 = Closed     - Claims window ended
6 = Reopen     - Ready to start next cycle
